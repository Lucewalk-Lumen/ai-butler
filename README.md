# ai-butler

**启明星** · v1.1.4 · `agent`

> Teacher Workbench butler: opens the single-file local PWA workbench, reads its snapshot to brief todos, deadlines and weekly progress, and manages scheduled automations. Fully local by default — your data never leaves the device.


Part of the [WorkBuddy Experts](https://github.com/Lucewalk/WorkBuddy-Experts) collection — expert teams, agents and skills for the WorkBuddy AI assistant platform.


## What it does

- A `agent`-type package; see the manifest at `.codebuddy-plugin/plugin.json` for capabilities.

## Install

1. Download the package zip from [Releases](https://github.com/Lucewalk/ai-butler/releases) or clone this repo;
2. Unzip keeping the internal manifest structure intact;
3. Import/register in WorkBuddy (custom connector → trust & enable).
